MANUAL

COMO JOGAR

Três jeitos de pilotar. O objetivo é o mesmo: sobreviver.

DualShock 4
  • Esquerdo — mover
  • Direito — mirar
  • R2 — atirar
  • Options — pausar
Teclado + mouse
  • WASD — mover
  • Mouse — mirar
  • Clique ou Espaço — atirar
  • Esc — pausar
Celular
  • Fixo, segue o dedo, ou metade da tela
  • Esquerda anda, direita mira e atira
  • O jeito muda em Configurações
  • O HUD também pode ser arrastado

Conecte o DualShock 4 e aperte qualquer botão.

No PC: WASD ou setas para mover, mouse para mirar, clique ou Espaço para atirar, Esc para pausar.

Clique na janela para o controle ser detectado. Nome, nave, opções e ranking ficam salvos para todos.
